# 辩论赛 AI 二辩 · 实时语音反驳系统

2 名同学 + 1 名 AI（二辩）组队。对方发言结束后，AI 在**数秒内**产出一段结构完整、可直接朗读的驳论，
自己「亲口」说出来；抢话、判停、说话人区分全部自动完成。

> 面向高中辩论赛（3v3，无四辩）设计：双方一辩为真人、二辩为 AI、三辩为真人。
> 本项目即「二辩」这一位 AI 的完整实现——后端推理链路 + 前端训练台 + 现场大屏。

## 能力总览

| 能力 | 说明 |
|---|---|
| **双出稿通道** | ① *级联*：LLM 出稿 + 独立 TTS，可注入技法库／考察口径；② *端到端 Omni*：文本入、直接出 PCM 音频 + 字幕，首音约 1 秒 |
| **抢跑（Streaming Pre-generate）** | 对方还在说时就先出一稿，只攒不播；对方一说完立刻放音，把十几秒的生成时间藏进对方发言期间 |
| **流式分句播报** | 出句即合成、边写边说；相邻短句自动合并成整段，预取 + 无缝续接，无句间断点 |
| **语义判停（EOU）** | 不看固定静默时长，而看末句是否收束：收束 0.8s 即接、未收束才等到 2.2s，另有纯规则快通道 0.07s |
| **说话人分离** | 分片 ASR + 逐句归属判定（`hall` / `ours` / `opp`），识别主席串场、区分敌我；片内可再拆分 |
| **主席点名发令枪** | 命中「有请我方二辩」立即发言，不等静默；命中「有请对方二辩」则明确不抢 |
| **长期记忆** | 滚动摘要本场已说／对方已说／已用论据，避免整场重复同一个论点 |
| **事实护栏** | 拦截编造的数字、机构、研究结论，命中即剔句并提示 |
| **纯净提示词模式** | 一键去掉全部辩论预设（技法库、考察口径），只留 TTS 对接所需的格式约束，供训练／接入方自定义 |
| **现场大屏** | 独立单文件页面：10 个环节计时、6 盏灯、抢话按钮、末 10 秒闪烁、可接 ESP32 实体按钮 |

## 快速开始

```bash
cp .env.example .env      # 填入各厂商 API Key
docker compose up -d --build
curl http://127.0.0.1:8000/healthz
```

最低只需配一个模型通道即可出稿；语音链路（ASR / TTS）需额外配硅基流动或阿里云百炼 Key。
所有 Key 均从环境变量读取，仓库内不含任何真实密钥。

环境变量分组：`DEBATE_STRONG_*`（出稿）/ `DEBATE_FAST_*`（结构·判停）/ `DEBATE_BACKUP_*`（降级）
/ `SILICONFLOW_*`（ASR + TTS）/ `DASHSCOPE_*`（百炼 ASR·TTS·Omni）。

## 延迟是怎么压下来的

端到端延迟的几个源头，逐项处理：

| 环节 | 措施 | 实测 |
|---|---|---|
| 说完判定 | 语义判停（看末句是否收束）+ 规则快通道 | 2.2s → **0.07~0.8s** |
| 生成 | **抢跑**：对方说到一半就开始出稿，音频先缓存不播 | 18s 折叠进对方发言期 |
| 生成（通道二） | Omni 端到端：一步出音频，省掉独立 TTS 一段 | 首音 **~1s** |
| 合成 | 流式 TTS + 预取 + 整段合并 + 无缝续接 | 首字节 0.07~0.29s |
| 边界 | 主席点名直接触发，不等静默 | — |

> 结论：抢跑成功时端到端约 **1.8s**；未抢跑时为完整出稿链路。

## 关键实测口径

- **TTS 语速**：辩论语速目标 300 字/分钟，实测 CosyVoice2（+8%）≈327 字/分、百炼 3.1-tts-flash ≈342 字/分，均达标。
- **稿长折算**：按 **5 字/秒** 折算（`lo = duration × 4.5`，`hi = duration × 5.5`），而非按字数估时长。
- **音色与模型必须版本对齐**：`longanhuan_v3.6` 配 3.0、`longanhuan_v3.1` 配 3.1，混用报 `Engine error [411]`。
- **倍速参数名逐端点不同**：`/audio/tts/SpeechSynthesizer` 用 `rate`，`/multimodal-generation/generation` 用 `speech_rate`。
- **纯净模式**（`no_strategy: true`）：40 秒目标实测 7 句 / 208 字；完整模式 4 句且强制含设问句。

## 发言人怎么判定（流程驱动，不再靠 AI 猜）

有大屏 + 实体按钮时，「现在是谁在说话」是**已知事实**，不需要也不该由语音模型去推测。

链路：

| 时点 | 广播事件 | 发言人 |
|---|---|---|
| 切换环节 | `stage{kind, side, seat, target, floor:"hall"}` | **主席 / 环节过渡**（环节之间的间隙必然是主席串场） |
| 大屏按空格开始计时 | `floor{who, reason:"stage-start"}` | 本环节默认发言方 |
| 选手按实体按钮 | `down{side, stage}` + `floor{who, reason:"button"}` | 该侧真人 |
| 自由辩论抢话 | `free_grant / free_deny / free_idle` | 抢到的一方（AI 让手 0~1000ms 可调） |
| AI 说完 | `ai_done` → 大屏广播 `floor` / `free_idle` | 交回对方 / 空出 |
| 计时停止 | `floor{who:"hall", reason:"stage-stop"}` | 回到主席 |

转写归属因此变成三分支，优先级从高到低：

1. **说话人分离标签已映射** → 直接用（最准）
2. **「用 AI 识别发言方」开关打开**（`cfg.attr`，默认关）→ 调 `/api/attribute`
3. **默认**：直接按流程 floor 落归属 —— **零模型调用、零延迟**

配套要点：

- **主席兜底**：`感谢正方一辩。下面有请反方二辩…` 这类串场语即使落在辩手时段也记为会场（纯正则，零调用），否则会被当成对方发言、触发误接话。
- **安全阀**：若从未收到任何大屏信息（单机调试），自动回退到 AI 识别，避免「一片都归会场、AI 永不接话」。
- **收益**：省掉每段 4~20 秒的归属判定；抢跑判定从「猜尾部是谁」变成「floor === opp」；失误来源从模型判断转为流程记录。

## 分段续写：边播边生成

抢跑稿不再是「一次写完整篇」。默认开启 `chunked` 后：

```
对方开口 ──► 只写第一段（约 45% 时长）──► 我方开口播放
                                          │
                                          ├─ 同时把「已说内容 + 对方在我方开口后新增的发言」
                                          │   交给模型续写第二段
                                          ▼
                                     第二段无缝接进同一条时间轴
```

- 请求约定：`chunk_sec`（首段秒数）与 `continuation{part, said, fresh, remain_sec}`
- `said` 保证**不重复**已说内容；`fresh` 是**我方开口之后**对方才说的话 → 后半段能真正回应对方的最新说法
- 首段占比可调（`chunkRatio`，0.30~0.70，默认 0.45）：调小更快融入新内容，调大首段更完整
- 关闭 `chunked` → 回到一次写全稿的旧行为

实测（线上，45 秒目标）：

| | 句数 | 字数 | 耗时 | 与已说内容重复 | 是否回应抢跑后的新发言 |
|---|---|---|---|---|---|
| 第一段 | 4 | 138 | 11.2 s | — | — |
| 续写第二段 | 4 | 170 | 8.4 s | 无 | ✓（精准接住「伦理规范会跟上」） |

## 我方论证体系（已注入提示词）

赛前准备稿已提炼进 `debate/prompts.py` 的 `TEAM_CASE`，随 `SYSTEM` 前置（命中前缀缓存），二辩每次出稿都带着它：

- **判准**：AI 是否拓展了人类创造所能达到的**高度（边界）**、**广度（路径）**与**可能（层次）**
- **三根支柱**：①被消解的是「人被当工具」的异化状态 ②AI 是能力的放大器 ③AI 越强越映照人的独特性（神笔马良）
- **三条防守铁律**：技能稀缺性下降 ≠ 价值消解（相机/绘画）｜个体阵痛 ≠ 整体趋势（工业革命）｜治理风险 ≠ 趋势消解
- **论据库**（只准用这四个，不许再编）：AlphaFold 两亿蛋白 ｜ 京东客服雨辰转 AI 训练师 ｜ 彭青云 AI 短剧《众神之战》 ｜ 素人用 AI 作曲破亿播放
- **绝对不要说**：工具性价值算人的价值 ｜ 用单个成功者当证据 ｜ 承认 AI 终将占据所有赛道

实测（线上，45 秒目标，三场不同攻击点）：

| 对方打法 | 输出 | 自动用上的素材 |
|---|---|---|
| 取代岗位→价值消解 | 7 句 / 366 字 / 15.5s | 雨辰、相机类比、「赛道转移不是赛道取消」 |
| 技能不值钱→消解 | 7 句 / 309 字 / 16.2s | 相机、彭青云、「稀缺性下降≠价值消解」 |
| 依赖 AI→主体性没了 | 7 句 / 333 字 / 12.0s | 计算器、破亿播放、「层次提升」 |

纯净模式（`no_strategy`，反方训练版）**不注入**这套内容——`SYSTEM_CLEAN` 保持空白人设。

## 对外接口

完整文档见 [`web/api-doc.md`](web/api-doc.md)，核心四个端点：

| 端点 | 用途 |
|---|---|
| `POST /api/rebut` | 级联出稿，SSE 逐句推送 |
| `POST /api/rebut-omni` | 端到端出稿，SSE 推 PCM 音频 + 字幕 |
| `POST /api/quick` | 2 句内快问快答（人机对辩主要形态） |
| `POST /api/attribute` | 逐句判定发言人归属 |

请求体关键参数：`topic` / `our_side` / `our_case` / `opponent` / `duration`（30–60 秒）
/ `system_extra`（自定义提示词，优先级最高）/ `no_strategy`（纯净模式）。
